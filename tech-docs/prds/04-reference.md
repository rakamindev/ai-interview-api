## PRD 04 — Technical Specification

#### Data models, API endpoints, audio format, error handling, and integration notes.

## 1. Data Models

#### All tables are scoped to tenant_id (existing Rakamin multi-tenant pattern). Auth and user management come from the existing

#### Rakamin platform — not built here.

### assessments

#### Stores the assessor’s config: role, time limit, skills to assess.

```
CREATE TABLE assessments (
id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
tenant_id UUID NOT NULL,
created_by UUID NOT NULL, -- FK to existing users table
name VARCHAR( 255 ) NOT NULL, -- e.g. "Senior Frontend Engineer"
time_limit_min INTEGER NOT NULL -- 30, 45, 60, or 90
CHECK (time_limit_min IN ( 30 , 45 , 60 , 90 )),
system_prompt TEXT, -- generated by N2 after save
created_at TIMESTAMPTZ DEFAULT NOW(),
updated_at TIMESTAMPTZ DEFAULT NOW()
);
```
### assessment_skills

#### One row per skill per assessment. Ordered (display_order).

```
CREATE TABLE assessment_skills (
id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
assessment_id UUID NOT NULL REFERENCES assessments(id) ON DELETE CASCADE,
skill_id VARCHAR( 50 ), -- B7 ID (e.g. "SK-ENG-001") or NULL for custom
skill_label VARCHAR( 255 ) NOT NULL, -- display name
is_custom BOOLEAN NOT NULL DEFAULT FALSE,
scope_include TEXT,
scope_exclude TEXT,
l1_anchor TEXT NOT NULL,
l2_anchor TEXT NOT NULL,
l3_anchor TEXT NOT NULL,
l4_anchor TEXT NOT NULL,
l5_anchor TEXT NOT NULL,
expected_level INTEGER -- 1-5, used in fit/gap
CHECK (expected_level BETWEEN 1 AND 5 ),
display_order INTEGER NOT NULL DEFAULT 0
);
```

### sessions

#### One session = one candidate interview attempt.

```
CREATE TYPE session_status AS ENUM ('pending', 'active', 'ended', 'failed');
CREATE TYPE end_reason AS ENUM ('manual_candidate', 'manual_assessor', 'all_covered', 'time_ceiling',
'error');
CREATE TABLE sessions (
id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
tenant_id UUID NOT NULL,
assessment_id UUID NOT NULL REFERENCES assessments(id),
candidate_id UUID, -- FK to existing users table (nullable: candidate may not have
Rakamin account)
invite_token VARCHAR( 64 ) UNIQUE NOT NULL,
status session_status NOT NULL DEFAULT 'pending',
end_reason end_reason,
started_at TIMESTAMPTZ,
ended_at TIMESTAMPTZ,
duration_seconds INTEGER,
gemini_resumption_token TEXT, -- latest SessionResumptionUpdate token
created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_sessions_invite_token ON sessions(invite_token);
CREATE INDEX idx_sessions_tenant_status ON sessions(tenant_id, status);
```
### transcript_turns

#### One row per conversational turn (AI or candidate).

```
CREATE TYPE speaker_type AS ENUM ('ai', 'candidate');
CREATE TABLE transcript_turns (
id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
session_id UUID NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
turn_number INTEGER NOT NULL,
speaker speaker_type NOT NULL,
text TEXT NOT NULL,
audio_start_ms INTEGER, -- offset from session start
audio_end_ms INTEGER,
created_at TIMESTAMPTZ DEFAULT NOW(),
UNIQUE (session_id, turn_number)
);
CREATE INDEX idx_transcript_session ON transcript_turns(session_id, turn_number);
```
### coverage_maps

#### One row per skill per session. Updated by N7 after each candidate turn.

```
CREATE TYPE coverage_state AS ENUM ('not_yet', 'initiated', 'partial', 'covered');
```

```
CREATE TABLE coverage_maps (
id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
session_id UUID NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
skill_id VARCHAR( 50 ), -- NULL for discovered skills
skill_label VARCHAR( 255 ) NOT NULL,
is_discovered BOOLEAN NOT NULL DEFAULT FALSE,

probe_count INTEGER NOT NULL DEFAULT 0 ,

UNIQUE (session_id, skill_label)

CREATE INDEX idx_coverage_session ON coverage_maps(session_id);
```
### portfolios

#### One portfolio per session. Generated by N10 after session ends.


### portfolio_skills

#### One row per skill in the portfolio. Includes both configured and discovered skills.

```
CREATE TYPE confidence_level AS ENUM ('high', 'medium', 'low');
CREATE TABLE portfolio_skills (

skill_id VARCHAR( 50 ),

is_discovered BOOLEAN NOT NULL DEFAULT FALSE,
ai_level INTEGER NOT NULL CHECK (ai_level BETWEEN 1 AND 5 ),
ai_confidence confidence_level NOT NULL,
evidence JSONB NOT NULL DEFAULT '[]', -- array of quote strings, max 3
competency_summary TEXT NOT NULL

```

## 4. System Prompt Generation (N2)

#### Triggered on POST /assessments and PUT /assessments/:id.

#### Input: assessment record + all assessment_skills

#### Output: system prompt string stored in assessments.system_prompt

#### Template is defined in prd/01-first-principles.md Section 2.

#### The generated prompt is stored, not generated at session-start time. This ensures:

#### Session start is fast (no generation delay)

#### Prompt is auditable (assessor can review what the AI was told)

#### Changes to assessment after session creation don’t affect in-progress sessions

## 6. Error Handling

### Gemini Live connection errors

### Coverage analyzer failures (N7)

#### N7 runs async and is non-critical. If it fails:

#### Log error

#### Coverage map is NOT updated for that turn

#### Interview continues normally (AI uses previous map state)

#### Do NOT retry N7 for the same turn (stale signal is acceptable; retry creates duplicates)
